SizeTrail is a permanently read-only macOS storage attribution explainer for developer toolchains. It never deletes, moves, or modifies anything; its only output is stdout and stderr.

## Why this release exists

v1.0.0 attributed Docker Desktop. The machine that now verifies the Docker adapter has no Docker.app; it runs OrbStack. Treating a leftover `desktop-linux` context, a PATH `docker`, or a generic `Docker Engine - Community` platform name as that proof would call a missing runtime present, or call a different product by the old name.

## What changed

The Docker probe closed set is unchanged in count and still never talks to the Engine API. Production now uses OrbStack's bundled CLI, the `orbstack` context, and the per-user OrbStack Unix socket. Version admission pins client and server versions together with the OrbStack kernel string. `Server.Platform.Name` is not enough.

The host disk is OrbStack's `data.img.raw` or `data.img` under the OrbStack Group Container, or a custom `data_dir` from `~/.orbstack/vmconfig.json`. `swap.img`, the app-bundle `rootfs.img`, and the `~/OrbStack` view mount are not measured. A successful daemon inventory no longer claims Desktop's inactive-store remainder; this runtime has no dual-store evidence.

Advice still prints vendor commands and never runs them. The commands now name `--context orbstack`. `--no-docker` remains an explicit user exclusion.

The scan document uses schema version 1.0.0.

## Known coverage boundary

Hosted CI does not install OrbStack. A runner without it reports `not_present` and must not be read as a live OrbStack proof. Group Container access can be policy-denied; that is a typed gap, not absence of OrbStack. This release does not reconcile Apple's System Data figure or promise a reclaim amount.

## Verifying what you downloaded

Check the archive against the published checksum file, run `sizetrail --version`, and confirm the architecture with `file sizetrail`. Each archive contains only the `sizetrail` binary.
