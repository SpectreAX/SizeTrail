SizeTrail is a permanently read-only macOS storage attribution explainer for developer toolchains. It never deletes, moves, or modifies anything; its only output is stdout and stderr.

## Why this release exists

v1.1.0 attributed OrbStack-hosted Docker. The next full-depth toolchain on this machine is Go. A PATH `go` or a `go env` lookup under `--root` would attribute the maintainer's real caches to a fixture home — the same class of error as leftover Docker Desktop sockets.

## What changed

The fourth compiled adapter measures the Go build cache and the Go module cache as independent roots. Locations come only from the scan home: the default directories, or absolute `GOCACHE` / `GOMODCACHE` keys in that home's `Library/Application Support/go/env` file. SizeTrail does not run `go env`, does not search `PATH`, and does not measure `GOROOT`, user source trees, or `GOTMPDIR`.

Version admission accepts only the checked-in version 1.26.6 token from `/opt/homebrew/bin/go` or `/usr/local/go/bin/go`. The version probe overrides the child `HOME` to `/var/empty` because `go version` writes local telemetry. An unknown version still measures those cache directories. `--no-go` remains an explicit user exclusion.

Advice still prints vendor commands and never runs them. The only rendered commands are `go clean -cache` and `go clean -modcache`.

The scan document uses schema version 1.0.0. GitHub release archives remain the only published install path.

## Known coverage boundary

Hosted CI does not require Go. A runner without either production binary reports `not_present` and must not be read as a live Go proof. A malformed GOENV file is a typed gap, not a guess at the default directories. This release does not reconcile Apple's System Data figure or promise a reclaim amount.

## Verifying what you downloaded

Check the archive against the published checksum file, run `sizetrail --version`, and confirm the architecture with `file sizetrail`. Each archive contains only the `sizetrail` binary.
